### Current Infrastructure Direction

The **Proxmox Workstation Platform** reached V2 and is now complete as a documented engineering experiment.

The project successfully demonstrated:

* GPU passthrough
* Linux and Windows workstation VMs
* Looking Glass
* OPNsense networking
* WireGuard management
* Monitoring
* Backup and recovery
* Disposable security environments

The next project keeps the useful virtualisation concepts while returning the primary Linux desktop to bare metal.

```text
Previous:
Hardware → Proxmox VE → Linux / Windows / Security VMs

Current:
Hardware → Ryoku Linux → KVM/QEMU/libvirt → VMs where useful
```

The Ryoku build will continue using **VFIO and GPU passthrough** for workloads that benefit from virtualisation without making the workstation itself a dedicated hypervisor.

A dedicated repository for the Ryoku platform is forthcoming.
