## 🖥️ Current Infrastructure Direction

The **Proxmox Workstation Platform** reached V2 and is now finished as a documented engineering experiment.

The project successfully demonstrated:

- GPU passthrough
- Linux and Windows workstation VMs
- Looking Glass
- OPNsense networking
- WireGuard management
- Monitoring
- Backup and recovery
- Disposable security VMs

The next workstation architecture keeps the useful virtualisation concepts while moving the primary Linux desktop back to bare metal.

```text
Previous architecture

Hardware
   ↓
Proxmox VE
   ↓
Linux / Windows / Security VMs


Next architecture

Hardware
   ↓
Ryoku Linux
   ↓
KVM / QEMU / libvirt
   ↓
VMs where useful
````

The new design will use **Ryoku Linux as the primary workstation OS**, with KVM/QEMU, libvirt, VFIO, and GPU passthrough for workloads that benefit from virtualisation.

A dedicated repository for the new platform is forthcoming.
